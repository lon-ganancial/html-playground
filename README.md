# HTML Playground

*A small experiment that turned into something much bigger.*

## The Idea

I originally thought this would be a quick project: a simple page where you could write HTML and immediately see the result.

But while exploring similar tools, I started noticing the little things we often take for granted. Resizable panels, keyboard shortcuts, automatic saving, responsive previews, and even how an editor highlights the code you're working on.

Individually, these details seem minor. Together, they make a tool feel effortless.

What started as a basic HTML editor gradually became a more complete playground.

## Features

**Code Editor**
- Syntax highlighting for HTML, CSS, and JavaScript
- Code formatting, folding, and search
- Dark and light themes, color picker, and keyboard shortcuts

**Live Preview**
- Instant HTML, CSS, and JavaScript preview
- Resizable editor and preview panels
- Responsive device presets and custom viewport sizes

**Element Inspector**
- Click an element in the preview to locate its HTML code
- Select code to highlight the matching element in the preview
- Inspect dimensions, spacing, borders, and typography

**Local Workspace**
- Create, upload, rename, duplicate, and delete HTML files
- Automatically save work in browser storage
- Export individual HTML files or download a ZIP archive

**Offline-Ready**
- Self-hosted editor tools, fonts, and formatting libraries
- No third-party CDN required for the application itself
- User-created pages can still load external resources

## What I Took Away

This project reminded me that even simple tools can have surprising depth.

A lot of the work wasn't about adding big features. It was about refining small interactions, removing friction, and understanding why familiar tools work the way they do.

Sometimes the details you barely notice are the ones that matter most.
